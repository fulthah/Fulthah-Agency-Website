## 🌍 About
Fulthah Agency is a professional recruitment and job placement website connecting talent with opportunities across Europe, Asia, and the Middle East.

## 🚀 Features
- Interactive world maps showing regions
- Job listings with custom icons
- Application form with validation
- CV/Resume upload
- WhatsApp & Email integration
- Fully responsive (desktop + mobile)
- 8,400+ people placed worldwide
